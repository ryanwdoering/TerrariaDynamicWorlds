Dynamic Worlds - Persistent World Progression + World Regeneration

Dynamic Worlds is a single-player focused tModLoader utility mod that lets you regenerate Terraria terrain without throwing away the playthrough built on top of it.

Use /regenworld [seed] to:
- snapshot world progression and preserved data
- save and exit the world cleanly
- run fresh Terraria/tModLoader worldgen through a loading screen
- restore protected builds, tiles, NPC state, and world progress
- automatically load back into the regenerated world

What gets preserved:
- Hardmode, game mode, world evil flag, ore tiers, boss flags, event flags, invasions, and world identity
- Town NPC roster, names, positions, and preserved housing when a valid home survives
- Bed spawn handling and safe fallback to world spawn
- Anchored tiles, structure zones, and container contents in preserved areas
- Vanilla pylon tile-entity registration for preserved vanilla pylons
- Calamity Mod progression including boss flags, difficulty modes, acid rain state, and crafting unlocks (when Calamity is installed)

Main systems:
- Reality Anchor: preserve exact tiles, walls, liquids, wires, and containers
- Reality Eraser: force specific tiles to clear to empty space after every regen
- Structure Anchor: preserve whole builds as movable structure zones
- Biome Dowser: automatically relocate preserved vanilla pylons to matching biomes with intelligent placement modes
- Automatic regen scheduler in single player with configurable interval
- Guide dialogue help page for the Reality Anchor
- Unified world tool overlay system: hold any tool to see all anchors, erasures, zones, and pylon placements
- Advanced configuration: control seed randomization, evil preservation, and cheat access

How the tools work:
- Hold any world tool to see anchors, erasures, structure zones, and Biome Dowser pylon zones together
- Reality Anchor left-clicks single tiles and drag-selects rectangles
- Reality Eraser left-clicks single tiles and drag-selects rectangles
- Structure Anchor click-drags structure zones and Shift-click removes a zone
- Biome Dowser click-drags pylon zones, right-click cycles placement modes, and Shift-click removes a zone
- Structure zones cannot overlap other structure zones
- Individually anchored tiles cannot overlap structure zones
- Pylon zones must contain exactly one vanilla pylon

Useful commands:
- /regenworld [seed]
- /snap
- /dwtools
- /dwinfo
- /dwzone [list|clear|clearall] [id]
- /clearzones
- /hardmode [on|off]    (requires Allow Cheats)
- /down <bossOrEvent>   (requires Allow Cheats)
- /killduplicatenpcs

Config options and planned placeholders:
- Enable Scheduled Regen: turns the automatic regen scheduler on or off
- Scheduled Regen Interval (Days): controls how many in-game days pass between scheduled regens
- Allow Cheats: enables /hardmode, /down, and inventory right-click actions on Reality Anchor and Reality Eraser
- Preserve Evil Type: keeps the old world evil after regen
- Preserve Dungeon Side: planned setting, not implemented yet, and may not appear in every config UI yet
- Preserve Biome Features: planned setting, not implemented yet, and may not appear in every config UI yet
- Randomize World Each Regen: use a fresh seed each time, or reuse the current seed when available

Mod compatibility:
- Calamity Mod support: preserves Calamity boss progression, difficulty modes, acid rain state, and crafting unlocks
- Single-player only
- Works best if the same mod list stays loaded before and after regen
- Preserved chest contents support modded items through tModLoader item serialization
- Modded tiles, walls, and town NPCs are more likely to survive if their source mods are still installed
- Compatibility is weaker for custom pylons, unusual tile entities, and major worldgen-overhaul mods

FAQ:
- Pylons: preserved vanilla pylons are automatically relocated to matching biomes using the Biome Dowser system. Create pylon zones around your pylon structures and choose the placement mode (Surface, Underground, or Floating) that best matches where you want them. The mod intelligently scans for a matching biome and relocates the structure there during regen. If no valid matching biome is found, the pylon stays at its current location. Pylons are also repaired after regen so they function again.
- In-game regen: regen starts in-game but immediately saves and exits to a loading screen. You are not moving around in the live world while generation is happening.
- Older worlds: if a world can still be loaded in your current setup, Dynamic Worlds can still snapshot and regenerate it. It cannot reconstruct an unknown original 1.3 seed or reproduce old 1.3 worldgen exactly.
- Changing world evil: yes, if Preserve Evil Type is turned off. The new world keeps the evil chosen by the generated result.
- Buried or embedded builds: Structure Anchor settles a build onto new ground and bridges small support gaps, but it does not fully generate a new hill around the structure unless that surrounding terrain was also preserved.
