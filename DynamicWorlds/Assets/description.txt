FAQ:
- Pylons: preserved vanilla pylons are automatically relocated to matching biomes using the Biome Dowser system. Create pylon zones around your pylon structures and choose the placement mode (Surface, Underground, or Floating) that best matches where you want them. The mod intelligently scans for a matching biome and relocates the structure there during regen. If no valid matching biome is found, the pylon stays at its current location. Pylons are also repaired after regen so they function again.
- In-game regen: regen starts in-game but immediately saves and exits to a loading screen. You are not moving around in the live world while generation is happening.
- Older worlds: if a world can still be loaded in your current setup, Dynamic Worlds can still snapshot and regenerate it. It cannot reconstruct an unknown original 1.3 seed or reproduce old 1.3 worldgen exactly.
- Changing world evil: yes, if Preserve Evil Type is turned off. The new world keeps the evil chosen by the generated result.
- Buried or embedded builds: Structure Anchor settles a build onto new ground and bridges small support gaps, but it does not fully generate a new hill around the structure unless that surrounding terrain was also preserved.
- Regen on death: when enabled in config, dying will trigger an automatic world regeneration in single-player mode. The world progression is preserved and restored after regen.
- Multiple regen cycles: use /multiregen to run the full regen flow multiple times, with the player being reloaded into the world between each cycle. Useful for testing or content creation.
